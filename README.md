## 策略逻辑

五层条件判断BTC 10分钟涨跌方向：

1. **Z-score < -2.0**（做多）/ **> +2.0**（做空）：价格偏离20分钟均线2个标准差
2. **RSI30 < 25**（做多）/ **> 75**（做空）：30分钟动能衰竭
3. **成交量 > 2.0x SMA20**：放量确认，有真实换手
4. **RSI5 < 22**（做多）/ **> 78**（做空）：5分钟极度超卖/超买
5. **10分钟后** c[i+10] vs c[i] 判断涨跌
